BUDOWANIE APK
A) Android Studio: File > Open > folder Tempo > poczekaj na sync > Build > Build APK(s).
   Plik: app/build/outputs/apk/debug/app-debug.apk
B) Bez Android Studio: wrzuć folder na GitHub (nowe repo), zakładka Actions > Build APK > pobierz artefakt "tempo-apk".
Potem przenies APK na telefon i zainstaluj (zezwol na instalacje z nieznanych zrodel).
